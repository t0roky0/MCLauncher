Вопросы

Это правда бесплатно?

Да. Лаунчер бесплатный, без рекламы и подписок.

Нужна ли лицензия Minecraft?

С аккаунтом Microsoft, где есть Minecraft, играешь как обычно, на любых серверах. Через Xbox-аккаунт без Java или гостем Java запускается офлайн: одиночная игра, LAN и серверы без лицензии работают, лицензионные серверы не пустят.

Почему Windows или браузер предупреждают о файле?

У установщика пока нет платной цифровой подписи, поэтому SmartScreen видит «неизвестного издателя». Нажми «Подробнее» → «Выполнить в любом случае». В браузере — «Сохранить».

Это безопасно для аккаунта?

Вход — только на странице Microsoft, пароль лаунчер не видит. Токены хранятся зашифрованными средствами Windows, пати и голос шифруются.

Как обновиться?

Скачай новую версию здесь и установи поверх — настройки, скины и установки останутся.

На каких системах работает?

Windows 10 и 11, 64-бит. Для Bedrock нужна установленная Minecraft for Windows.
